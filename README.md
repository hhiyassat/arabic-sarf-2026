# arabic-sarf-2026

استخراج العوامل النحوية من الآيات القرآنية وتقطيعها مقطعياً (CV).

## البنية

الكود في الحزمة `sarf/`، كل وحدة بمسؤولية واحدة:

| الوحدة | الوظيفة |
|---|---|
| `sarf/chars.py` | الحروف والعلامات: الثوابت، وتفكيك الكلمة إلى (حرف، علامات)، وأدوات الحروف |
| `sarf/normalize.py` | التطبيع: الرسم العثماني إلى إملائي (مستوى النص)، والألف المحذوفة والمدّة والهمزات (مستوى الكلمة) |
| `sarf/divine.py` | لفظ الجلالة بكل صيغه |
| `sarf/syllabify.py` | المقطِّع CV: CVmap ∘ Resolve ∘ Syllabify ∘ Classify |
| `sarf/catalog.py` | فهرس العوامل: الوحدة (الصيغة، المجموعة) ← معانيها |
| `sarf/match.py` | مطابقة العوامل في الكلمة |
| `sarf/affix.py` | مقشِّر الزوائد: فعل أم اسم، وحرف المضارعة واللواحق (نون الرفع، واو الجماعة، ياء المخاطبة، نون التوكيد، ضمير الرفع، تاء التأنيث الساكنة)، وعلامة الآخر، والأمر بلا همزة وصل (قُلْ) بسكون آخره ما لم يكن في ملف المبنيات. لا يُقشَّر إلا من «سألتمونيها» واللواحق، وما سواهما جذري |
| `sarf/evidence.py` | نفي المرشَّح بالكتابة، على تحليل `affix` لما بعد العامل |
| `sarf/lexicon.py` | معجم المبنيات للبحث بالصورة المشكولة |
| `sarf/segment.py` | المقشِّر: خانات الكلمة (عامل، مبني، أل، جذع، لفظ الجلالة)، وشرط الفصل، والعامل ← المعمول، وتقطيع ما ليس عاملاً ولا مبنياً |
| `sarf/align.py` | ربط العامل بخانته وعلاقته |
| `sarf/pipeline.py` | تشغيل المراحل بالترتيب على كائن واحد للآية: normalize ← match ← evidence ← segment ← judge ← syllabify ← align |
| `sarf/status.py` | حالات المرشَّح (T09): مؤجَّل، ممنوع، مقبول |
| `sarf/judge.py` | الحكم (T09): مقبول بدليل إيجابي فقط (سبب + شرط + قواعد مفحوصة + لا منافس على الخانة)، وإلا مؤجَّل مع ذكر السبب؛ والممنوع ما نفته الكتابة |
| `sarf/analyze.py` | تحليل آية بكل المراحل (يمرّ بالـ pipeline) |
| `sarf/mood.py` | خبري/إنشائي/مؤجَّل بالعامل في بابه، بمعيار القسمة المعتمد (Q01): 18 إنشائية، و80 خبرية، ولَوْ وكَمْ مؤجَّلتان (T14a) |
| `sarf/output_text.py`، `sarf/output_html.py` | الناتج النصي وJSON، وتقرير HTML |

## التشغيل (Python 3 فقط، بلا مكتبات خارجية)

النص يُعالَج كما هو: كل كلمة تُقطَّع مستقلّة بحركاتها المكتوبة، بلا وصل بين الكلمات ولا وقف في آخرها. والتنوين حركة واحدة من جنسه، وهمزة الوصل في أول الكلمة تُنطق ابتداءً. ورموز الأداء تُحذف في التطبيع: واو الصلة وياؤها الصغيرتان (ۥ ۦ)، وعلامة المدّ (ٓ)، والألف الخنجرية على الألف المقصورة (مُوسَىٰ ← مُوسَى).

```
python3 extract_operators.py "إِنَّ ٱللَّهَ غَفُورٌ رَّحِيمٌ"
python3 extract_operators.py -f verses.txt            # آية في كل سطر
python3 extract_operators.py -f verses.txt --json     # JSON Lines
python3 extract_operators.py --uthmani on "مِن قَبْلِ"  # عامِل النص عثمانياً (auto/on/off): يُدرج السكون الضمني
python3 cv_syllabifier.py verse.txt                   # التقطيع وحده
python3 syllable_report.py -f verses.txt verses_inna.txt verses_innama.txt verses_allah.txt -o reports/syllable_report.html
```

خيار `--uthmani {auto,on,off}` (الافتراضي `auto`): يتحكّم في المعاملة العثمانية (السكون الضمني غير المكتوب). `auto` يكتشف تلقائياً بوجود علامة عثمانية (مثل ٱ)؛ `on` يعامل النص عثمانياً دائماً؛ `off` لا يعامله أبداً. مفيد للنص العثماني القصير بلا علامات (`--uthmani on "مِن قَبْلِ"`). متوفّر في `extract_operators.py` و`syllable_report.py`.

## الخانات: ما يُقطَّع وما لا يُقطَّع

تُجزَّأ الكلمة خانات لكلٍّ منها نوع:
- **عامل** (من فهرس العوامل): لا يُقطَّع، ويُعرض «عامل».
- **مبني** (ما في ملف المبنيات `02_mabniyat` وحده: الكلمة المبنية، وحرف العطف، وما الكافة، والضمير المتصل بصوره): لا يُقطَّع، ويُعرض «مبني».
- **لفظ الجلالة**: لا يُقطَّع.
- **أل التعريف** و**الجذع**، ومنه الفعل الماضي والأمر (مبنيان، لكنهما ليسا في الملف): تُقطَّع CV.

لا تُفصل خانة عمّا قبلها إلا إذا بدأت بحرف متحرك، فيكون حدّها حدَّ مقطع: «فَلْيَكْتُبْ» = [فَلْ][يَكْتُبْ]، و«وَٱمْسَحُوا» لا تُفصل. والشدة على الحدّ نصفها الأول للسابقة: «النَّاسِ» = [ءَنْ: أل][نَاسِ]. ولكل عامل معمول تُسجَّل حالته المتوقَّعة، وتُقارَن بالعلامة المكتوبة على الاسم بعد الجار وإنّ وكان.

## لفظ الجلالة

ليس كمثله شيء: يُعرَف كلمةً واحدة بكل صيغه وما يتصل به من سوابق (وَ، فَ، بِ، تَ، لِ، وهمزة الاستفهام ءَ) ولاحقة «ـمَّ» (`divine_name` في `sarf/divine.py`)، **ولا يُقطَّع**: لا مقاطع له ولا يدخل في عدّ المقاطع، ويُعرض في التقطيع كما هو موسوماً «لفظ الجلالة». أما استخراج العوامل (لِ في لِلَّهِ، بِ في بِٱللَّهِ) والتحليل الصرفي فتشمله كغيره. أمثلته في `verses_allah.txt`: ٱللَّه، لِلَّه، فَلِلَّه، تَٱللَّه، ءَآللَّه، ٱللَّهُمَّ — ولا يطابق ما يشبهه رسماً مثل ٱللَّهْو.
