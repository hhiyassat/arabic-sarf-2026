# سجل التغطية

يمنع إخفاء النقص: وجود اسم المرحلة لا يعني أن قواعدها منفَّذة، ولا أنها تغطي العربية كلها.

- `registry.jsonl`: سطرٌ لكل بابٍ أو سمةٍ أو علاقة، بمرحلته (من المعمار المقترح ذي المراحل الثلاثين)، وحالته، وما يثبتها.
- `checklist.json`: قائمة الحصر. كل بابٍ فيها يجب أن يكون في السجل بمرحلته؛ وحذف بابٍ منها تعديلٌ للحصر يُعلَن.
- `STATUS.md`: مولَّد، لا يُحرَّر باليد.

| المرتبة | ما يثبتها |
|---|---|
| غير ممثَّل (`unrepresented`) | التعريف وحده |
| ممثَّل بلا قاعدة (`represented`) | + التمثيل المطلوب |
| قاعدة غير منفَّذة (`rule_written`) | + القاعدة ومرجعها |
| منفَّذ غير مختبَر (`implemented`) | + الشيفرة: ملفٌّ ورمزٌ موجودان |
| مختبَر في نطاق (`tested`) | + الاختبار (ملفٌّ ونصّ الفحص فيه) والنطاق؛ ولا يُدَّعى «القرآن كله» بلا قياسٍ مسجَّل |

    python3 tools/check_coverage.py          # الفحص، ويكتب STATUS.md
    python3 tools/check_coverage.py --run    # ويشغّل ملفات الاختبار المذكورة
    python3 tests/test_coverage.py           # الفحص يمسك ما يُخفي النقص

**حالة المسوّدة:** المراحل الثلاثون وقوائم الحصر مقترحٌ من المعمار المعروض على صاحب النظرية، ولم تُعتمد بعد. وما فيه من جرد الفئات (فئات الاسم، أنواع الجمع، الأبواب) مقترحٌ ينتظر اعتماده.
